Task tracker app with data persistence using SwiftUI and SwiftData  

Features:
- add tasks
- mark tasks as complete
- swipe to delete tasks
- tap to dismiss keyboard  

To test: plug iphone into mac, select it as run destination, then build and run (also on iphone enable developer mode and trust developer)
